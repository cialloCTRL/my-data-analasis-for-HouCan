# 厚粲杯论文分析包（无 RRS 版）

按导师意见**整体剔除反刍（RRS）**后重建的完整论文分析包。原论文中 RRS 三个分量表（症状反刍/强迫思考/反省深思）与总量表，以及基于它们的所有分析（相关、分层回归、机器学习）已全部移除；其余分析全部从原始数据重新计算。

## 分析层级（对应论文第 5 章）

1. **描述性统计**（N=199；年龄/性别；α；操纵检查；量表均分）
2. **相关分析**（量表 5×5 相关 + 热力图；TextMind 137 变量 × 依恋 3 指标）
3. **分层回归**（L1 人口学 → L2 抑郁+焦虑 → L3 9 个词汇类别块，块级 ΔR²）
4. **LLM 相关分析**（ICC；描述统计；效标关联效度；增量效度；会聚效度）
5. **机器学习（探索性）**（词典 LASSO；LLM 语言块 LASSO；语义嵌入 LASSO；样本外对比）

## 数据说明

- 主表全部使用 ASCII 列名（`pid/age/gender`、英文量表列、`LLM_*` 英文维度列），中文说明见各文件「变量说明」sheet。
- `gender`：1=男，0=女（原 Q3 派生；**不要**命名为 male，避免与 TextMind 的 `male`（男性参照词频）变量冲突）。
- LLM 融合评分 =（DeepSeek 5 次均值 + 通义千问 5 次均值）/ 2，由 `forhoucan/llm_coding/results_*.csv` 离线计算。

## 复现

各子文件夹 `readme.md` 有运行方法；脚本均以相对路径引用 `数据/`，整个包可整体拷贝。依赖：R（openxlsx/psych/corrplot/car/glmnet）+ Python（numpy/openpyxl）。
