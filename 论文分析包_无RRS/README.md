# 厚粲杯论文分析包

本分析包是《基于对话语言行为的人机依恋识别研究》论文的完整数据分析交付物，覆盖论文第 5 章的全部分析层级，所有结果均可复现。心理特质聚焦**抑郁（PHQ-9）与焦虑（GAD-7）**两大维度，结合真实人机对话语言（TextMind 词典法 + 大语言模型编码）考察人机依恋的可识别信号。

## 分析内容（对应论文第 5 章）

1. **描述性统计**（5.2 节）：N = 199；年龄/性别分布；量表 Cronbach's α；操纵检查（单样本 t 检验）；关键量表均分
2. **相关分析**（5.3 节）：量表 5×5 相关矩阵与热力图（图四）；TextMind 137 变量与依恋 3 指标的相关（附图一/二）
3. **分层回归**（5.5 节）：L1 人口学 → L2 抑郁+焦虑 → L3 九个词汇类别块，报告块级 ΔR²/ΔF/Δp（表七~表十、附表一）
4. **LLM 相关分析**（5.6 节）：双模型融合评分的一致性 ICC（表十一）；描述统计；效标关联效度（附表四）；增量效度（表十二）；与 TextMind 的会聚效度（表十三）
5. **机器学习·探索性**（5.7 节）：词典 LASSO（附表二/三）；LLM 语言块与语义嵌入的样本外对比（附录五）

## 怎么用

### 1. 看结果（不改代码）
- 打开 **`所有分析的最终结果.md`**：第 0 节是文件索引，指明每个结果对应哪个文件夹里的哪张表/图；第 1~7 节是全部结果与主要结论。
- 各分析文件夹内的 **`表格.md`**：该分析的全部表格；**`图片/`**：热力图等图形。
- 每个文件夹的 **`readme.md`**：该分析做了什么、输入输出是什么、怎么运行。

### 2. 复现（重跑全部分析）
各文件夹 `代码/` 内是可运行脚本，全部以**相对路径**引用 `数据/`，整个包可整体拷贝到任意位置运行。

运行顺序（01 → 05；05 内先 R 后 Python）：

```bash
Rscript 01_描述性统计/代码/01_描述性统计.R
Rscript 02_相关分析/代码/02_相关分析.R
Rscript 03_分层回归/代码/03_分层回归.R
Rscript 04_LLM相关分析/代码/04_LLM相关分析.R
Rscript 05_机器学习/代码/05a_TextMind_LASSO.R
python 05_机器学习/代码/05b_样本外对比.py
```

依赖：**R**（`openxlsx`、`psych`、`corrplot`、`car`、`glmnet`）+ **Python**（`numpy`、`openpyxl`）。脚本运行后自动覆盖对应文件夹的 `表格.md` 与 `图片/`。

### 3. 数据说明
- 主表列名为 ASCII（`pid` / `age` / `gender`、英文量表列、`LLM_*` 维度列），中文说明见各文件「变量说明」sheet。
- `gender`：1 = 男，0 = 女。
- 量表：人机依恋（EHARS/CAIDS，焦虑 4 题 + 回避 3 题）、抑郁 PHQ-9（9 题）、焦虑 GAD-7（7 题），均取条目均分参与分析。
- TextMind：SCLIWC2024 词典 143 个语言特征，剔除 6 个零方差变量后 137 个进入分析，按理论先验映射为 9 个词汇类别块。
- LLM 融合评分 =（DeepSeek 5 次均值 + 通义千问 5 次均值）/ 2，共 10 维（2 依恋特质 + 8 语言维度），离线计算，不调用任何 API。
- 机器学习划分（169/30、149/50）与语义嵌入（embeddings.npz）均复用原管线的固定产物，保证可比性。

### 4. 与论文配套
- 论文正文（`厚粲杯论文0830.1.9版本.docx`）与本分析包位于同一目录；正文中的表格/图与包内 `表格.md` / `图片/` 一一对应，正文未内嵌的图（如热力图）可按 `所有分析的最终结果.md` 第 0 节索引插入。
