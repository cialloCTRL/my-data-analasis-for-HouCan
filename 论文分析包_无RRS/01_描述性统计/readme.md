# 01 描述性统计

## 目的
报告无 RRS 版描述性统计：样本量、年龄/性别分布、各量表 Cronbach's α、操纵检查（单样本 t 检验 vs 4 分中点）、关键量表均分。

## 与旧版（含 RRS）的差异
- **删除**：RRS 总量表及症状反刍/强迫思考/反省深思的 α（原 0.947/0.937/0.841/0.777 不再报告）与均分。
- **保留**：样本描述、EHARS（CAIDS）三指标、PHQ-9、GAD-7、操纵检查——这些与 RRS 无关，数值不变。

## 输入
- `../数据/数据_去RRS新版.xlsx`（sheet = 数据）

## 运行
```r
Rscript 代码/01_描述性统计.R
```

## 输出
- `表格.md`：全部描述性统计表

## 依赖
R 包：`openxlsx`、`psych`
