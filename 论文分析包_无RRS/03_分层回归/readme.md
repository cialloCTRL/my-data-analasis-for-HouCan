# 03 分层回归

## 目的
无 RRS 版理论驱动分层回归：
- **L1** 人口学：年龄、性别
- **L2** 量表：抑郁（PHQ-9）、焦虑（GAD-7）——**已剔除 RRS**
- **L3** 词汇类别块：9 个理论映射的 TextMind 类别块，逐块独立检验块级 ΔR²/ΔF/Δp

对应论文表七（量表层增量）、表八（量表标准化 β）、表九/表十（类别块增量）。

## 与旧版（含 RRS）的差异
- **L2 由 3 个量表（PHQ9+GAD7+RRS_total）减为 2 个（PHQ9+GAD7）**：
  - 表七 ΔR²/ΔF/Δp 全部重算（新值变小，因少了 RRS 的解释贡献）；
  - 表八 β 只剩抑郁/焦虑两列（原强迫思考 β=0.401 等反刍成分全部删除）；
  - 表九/表十块级 ΔR² 随 L2 基准变化而重算；
  - 原 H1 结论"强迫思考预测依恋焦虑/总依恋"删除，H1 变为"抑郁、焦虑预测人机依恋"。
- **rrs_components.R（反刍成分分析）整体作废**，不再出现在本包。

## 输入
- `../数据/数据_去RRS新版.xlsx`（sheet = 数据）

```r
Rscript 代码/03_分层回归.R
```

## 输出
- `表格.md`：量表层增量表、L2 β 表、3 个依恋指标的类别块增量表、显著块汇总
