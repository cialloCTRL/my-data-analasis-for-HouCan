# 02 相关分析

## 目的
无 RRS 版相关分析：
1. **量表间相关**：5 个量表（依恋焦虑/依恋回避/总依恋/抑郁 PHQ9/焦虑 GAD7）的皮尔逊相关矩阵 + 热力图。
2. **TextMind × 依恋**：137 个语言特征与 3 个依恋指标的相关（零方差剔除），显著变量表 + 热力图。

## 与旧版（含 RRS）的差异
- **量表相关由 9×9 缩减为 5×5**：删除症状反刍/强迫思考/反省深思/反刍总量表 4 行 4 列；原"依恋焦虑与反刍各维度 r = 0.19–0.33"不再报告。
- TextMind × 依恋相关不涉及 RRS，数值不变（此处照常重算确认）。

## 输入
- `../数据/数据_去RRS新版.xlsx`（sheet = 数据）
